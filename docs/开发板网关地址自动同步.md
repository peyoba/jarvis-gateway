# 开发板网关地址自动同步

固件把网关地址保存在 NVS 的 `hatch.host` 里，开机时读一次就再也不会变。Mac 的局域网地址一旦变化（DHCP 续租到新地址、切换 Wi-Fi/有线、换路由器），开发板就会持续连不上网关：按键有反应，但没有回音、也没有任何提示。

硬件侧没有可靠的自动发现通道可用：固件不解析 mDNS，路由器通常也不解析局域网主机名，BLE 在配网完成后就关掉了。因此这里选择最稳妥的一条路——**USB 串口直接写 NVS**。

## 原理

开发板的 setup 控制台认这些命令（串口 115200，输入 `>` 开头）：

```text
>hatch.host=192.168.0.102
cmd hatch.host=192.168.0.102
-> ok
```

`ip_sync` 打开串口、写入这一行、等到 `cmd hatch.host=... -> ok` 回显即视为成功；板子会把地址存进 NVS，下次开机直接使用。

## 控制台

打开 `http://<Mac 的局域网地址>:18888/`，「开发板地址」面板里有四个只读值和两个按钮：

| 位置 | 含义 |
| --- | --- |
| Mac 局域网地址 | 网关当前对外服务的地址，就是会被写进板子的值 |
| 板子已写入 | `run/gateway_ip.txt` 里记录的、上一次成功写入的地址 |
| 串口 | 探测到的开发板串口；没插板子时显示「未找到串口」 |
| 最近一次 | 上一次写入的结果和时间；鼠标悬停可看固件回显 |

- **同步到开发板**：等价于 `./jarvis ip-sync`。地址和板子里的一致时直接跳过，不碰串口（也就不会让板子复位）。
- **写入指定地址**：填一个地址再点，等价于 `./jarvis ip-sync --ip …`。给路由器上的固定租约、或者别的网段用。

写入在后台线程里跑，页面每 4 秒取一次 `GET /board`；写的过程中按钮会禁用，结束后面板显示「已写入 …，板子正在重新联网」。接口本身是 `GET /board` 和 `POST /board`（body `{"host": "1.2.3.4"}` 或空对象），非法地址在打开串口之前就返回 400。

## 手动同步

```bash
./jarvis ip-sync                                  # 取本机地址写入；地址没变就跳过
./jarvis ip-sync --ip 192.168.0.102               # 指定地址（例如路由器上看到的保留地址）
./jarvis ip-sync --port /dev/cu.usbserial-10      # 指定串口（插了多块板子时）
./jarvis ip-sync --force                          # 地址没变也重写一次
./jarvis ip-sync --json                           # 输出 {"ok","ip","port","detail"}，便于脚本调用
```

串口需要 `pyserial`：`venv/bin/pip install pyserial`，或安装可选依赖 `pip install 'jarvis-gateway[serial]'`。缺失时命令会明确提示，不会静默失败。

## 后台守护

```bash
./jarvis ip-guard start     # 每 10 秒比对一次本机地址，变化就自动写回开发板
./jarvis ip-guard status
./jarvis ip-guard stop
```

- 守护用文件锁（`run/ip_guard.lock`）保证单实例，重复启动会被拒绝。
- 已同步的地址记录在 `run/gateway_ip.txt`；`jarvis status` 会显示它和守护进程状态。
- 日志在 `logs/ip_guard.log`，成功写入时同时发一条 macOS 通知。
- 写入失败（板子没插、串口被占用）会每 60 秒记一次日志并持续重试，不会刷屏。

## 菜单栏 App

`Jarvis.app` 的菜单里也有**同步网关地址到开发板**和**手动指定网关地址…**两项，效果与上面两个按钮相同。它适合在浏览器还没打开时用；日常换网络、或者想从手机上点一下，用控制台更方便。

## 注意事项

- **打开串口会让开发板复位约 7 秒**：CP2102N 的 DTR/RTS 接在复位电路上。所以只在地址确实变化时才写入，别把它当成轮询探活。
- 串口同一时间只能被一个程序占用；开着 `idf.py monitor` 或串口助手时写入会失败。
- 开发板不在本机插着（远程调试、换了台电脑）时无法写入；此时可以在板子本机的「Server」设置项里手改。
- 更省事的做法是在路由器上给 Mac 配一个 DHCP 固定租约（例如始终 `192.168.0.102`），从源头减少地址变化——自动同步是兜底，不是替代。
- 地址未变化时 `ip-sync` 以退出码 0 跳过，可以放心写进脚本或登录项反复执行。
